# Cheeko Website Assets

Place website assets in this folder using the filenames below. If an asset is not ready yet, leave it empty and we will use placeholders during development.

## Recommended Formats

- Logos/icons/hand-drawn lines: `.svg` preferred.
- Photos/lifestyle images: `.jpg`, `.png`, or `.webp` at 2x.
- Product cutouts/composite cards: transparent `.png` or `.webp` at 2x.
- App mockups/screens: `.png` or `.webp` at 2x.
- Keep filenames lowercase with hyphens.
